The licenses

Three tiers, each granting what the one before it does and more. A license belongs to a person, on their Consensus-AI account, never to a server: sign in anywhere and it is there. The tiers are not roles: a project's roles (Owner, Member, Service, Watcher) stay as they are.

Free

The desktop and the sidecar

  • The freely available feature set, with no account and no sign-in.
  • Run the desktop to work with projects in local folders.
  • Run the sidecar on localhost: the API and MCP of the open project, for an agent session beside it.
  • Copy the sidecar instructions for the project in the desktop.
  • No LLM connections and no LLM tasks: the sidecar is the free tier's LLM path.
Personal

The LLM tasks and the Server Host on this machine

  • Use the LLM connections and all the LLM tasks in the desktop.
  • Connect the desktop to a project a Server Host serves.
  • Run the Server Host bound to localhost.
  • Use the Server Host to manage mounted projects, LLM connections and users.
Professional

The Server Host on the network

  • Everything Personal grants.
  • Bind the Server Host to the network, local network and remote alike; the trusted-network setting stays on the Host.
  • Be the Administrator of a Public server.

Where the tiers are enforced: a Public server refuses a sign-in below what the person's roles need, naming the tier; the desktop reads its tier from the sign-in and keeps it for fourteen days offline, falling back to Free with a line in About when the cache lapses, and nothing a person saved is ever locked away. A site license is a Consensus-AI organization carrying the license for its members, capped at the seats bought.

Prices are not set yet: the tiers are built, the store is not. Consensus-AI is not Consensus, the research search engine at consensus.app, and has no connection to it.
