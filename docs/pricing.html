The licenses

Four tiers, each granting what the one before it does and more. A license belongs to a person, on their Consensus-AI account, never to a server: sign in anywhere and it is there. The tiers are not roles: on a Server anyone signed in may hold any project role (Owner, Member, Service, Watcher), under the Administrator's license.

Unlicensed

The desktop and the sidecar

  • No account and no sign-in.
  • Run Consensus Desktop to work with projects in local folders.
  • The sidecar on localhost: the API and MCP of the open project, for an agent session beside it.
  • Copy the sidecar instructions for the project in the desktop.
  • No LLM connections, tasks or users in the desktop: the agent session is the LLM's way in.
Registered

Free, signed in: the desktop connects to Servers

  • Everything Unlicensed grants.
  • Connect the desktop to Servers, on this machine and remote, as a thin client.
  • Hold any role in a Server's projects, and use the LLM tasks the Server offers; they run on the Server.
  • Be a Manager of a Server.
  • Cannot run a Server.
Personal

The Server on this machine

  • Everything Registered grants.
  • Run Consensus Server listening on localhost, and be its Administrator.
  • Manage its users, LLM connections and tasks, and projects, with Managers you choose.
Professional

The Server on the network

  • Everything Personal grants.
  • Run the Server listening on public addresses, the local network and remote alike (Scope Public).

Where the tiers are enforced: a Server opens only under its Administrator's Personal or Professional license, and listens on the network only under a Professional one; the desktop connects to a Server only when someone is signed in. The signed-in person is kept on the machine for fourteen days without a check, and then signed out, with a line in About; nothing a person saved is ever locked away. A site license is a Consensus-AI organization carrying the license for its members, capped at the seats bought.

Prices are not set yet: the tiers are built, the store is not. Consensus-AI is not Consensus, the research search engine at consensus.app, and has no connection to it.
