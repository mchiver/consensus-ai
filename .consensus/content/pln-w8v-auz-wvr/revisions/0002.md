# Run Shapes

Consensus is deployed through a command line invocation.


## Current Implementation

The following command line arguments are curtrently supported:
- `--data <folder>`: the data folder; ~data beside the checkout by default
- `--port <port>`:  the port to listen on; the settings' Port, else 3500
- `--host <address>`: the address to listen on; the settings' Host, else 127.0.0.1; 0.0.0.0 for every interface
- `--help, -h`: prints the usage line and exits


## Proposed Changes

Consensus always loads its global config from the system's user folder `<user>/.consensus/consensus.json`.

The global config contains:

    - global settings
        - Server name
        - address, port
    - list of local LLMs
        - User name, Type, etc.
        - visibility
    - list of local Projects
        - local path
        - filters, etc.
        - visibility
    - list of servers
        - connection info
        - last view settings

A Consensus server serves a number of configured Projects and LLMs.

Each Project is tied directly to a locally accessible folder.
This folder serves as the context for all project plans and LLM interaction.
This folder contains a `.consensus` subfoider which stores:

- the configuration file for the project `.consensus/project.json`
- the project's data files (further context, plans, threads, indexes, etc.).

if a `.consensus` folder does not exist, one is created and initialized.


### Command Line Arguments

- `--config <folder>`: Global config path. Defaults to the system's user folder `<user>/.consensus`.
- `--project <folder>` Folder to the root of the project. Folder should have/create a `.consensus` subfolder. When `--project` is used, the server starts desktop launches and connects to this project. This is the way to perform ad-hoc consensus sessions in local folders.
- `--port <port>`:  Port to listen on; the settings' Port. Defaults to 3500.
- `--host <address>`: Address to listen on; the settings' Host. Defaults to 127.0.0.1; 0.0.0.0 for every interface


## Invocation Scenarios

**Run Without Arguments**

Loads global config from `<user>/.consensus`.
