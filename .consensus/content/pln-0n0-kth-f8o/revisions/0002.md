# Build Workflow

How a plan goes from agreed to built, and who does what. Two kinds of LLM take part:

- **One-shot LLM** (Send to LLM, for example an Ollama model): gets one fully packed prompt and answers with one JSON object. It reviews, replies, applies resolved threads and keeps the project's context. It has no tools, so it never builds.
- **Interactive agent** (Claude Code, driven by the owner in a terminal session): reads and writes the codebase and works in Consensus through its API. It initializes project contexts and implements plans.

## The build loop

1. **Ready.** Every thread in the plan is resolved and applied.
2. **Instruct.** The owner tells the agent to implement the plan.
3. **Implement.** The agent implements what the plan says, and only that. It runs the tests.
4. **Report.** The agent posts one contested whole-document thread on the plan: the build log, saying what was built, where, and how it was checked.
5. **Accept.** The owner resolves the build log thread; the agent then applies it (outcome only, no text change).
   - Accepting also commits the work: one commit titled after the plan, with a summary of the build log and no attribution trailers. Until then the work stays uncommitted, so a send-back is fixed in place.
6. **Or send back.** The owner replies to the build log instead. The agent fixes what the reply asks and replies with the new result; the loop goes on until the owner resolves it.

## Around the loop

- **Before building:** a plan with any contested thread is not ready; the agent says which threads are open and stops.
- **While building:** the plan's state is Working.
- **After acceptance:** the plan's state becomes Finished, and the project's context records what changed.
- **Starting a project:** the agent creates the project, uploads the codebase, and initializes its context; after that, plans are drafted, reviewed by the one-shot LLM, and discussed in threads as usual.

## Where the workflow is written down

- `.guides/build-with-consensus.md` in each repo: the loop above, for any agent session.
- The one-shot LLM's rules: that it reviews and applies, but never builds, and says so if asked to.
