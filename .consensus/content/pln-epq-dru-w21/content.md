# Step 6: Guide and Smokes

The last step of plan UI Components: the guide and its pictures, the help, and the smokes, brought up to date with the componentized page.

Decided: the server's node tests keep passing untouched; each step ends with the Electron smoke and a look at the page. No test framework is added for the components. This step retakes the guide's pictures that changed (the header with its location line and size, the thread pane, the title bar), rewrites the guide's Tabs section for the global filter, and updates Help > Hotkeys where a key changed.

Export and import: Import in a server row's menu. Projects: checked. The landing page needs nothing.
2. The repository's README.md gets the same facts where it is stale (Help above the tree, Settings at the bottom of the sidebar, the hotkeys sentence).
3. All pictures retaken in both themes with `node bin/docs.js screenshots`; one new picture, title-bar (the bar with the look popover open), for Getting started and Settings. The desktop's pictures stay captures of the page, with no window buttons; the text says what the window looks like. The tool's theme step goes through the theme module.
4.
