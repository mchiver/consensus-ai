# Sidecar Edition

We are going to simplify things greatly.

We are going to rebrand Desktop as Sidecar and remove all server and multiuser functionality.
This app opens only a local project folder and never connects to a Server.
This app never asks for a user sign-in.
This app is used only in sidecar mode.

This app's settings are stored in `sidecar.json` file.
Settings includes all view options, view state, user name, etc. that it does today.
