# Project Import and Export


We need to be able to export and import entire projects at a time.
This can be used for archiving as well as for transfer to another Consensus server.

The export artifact should be a json structure representing the Project and all of its items.
Specifically Context, folder structure, all plans and sub-plans, all threads for all plans in the project.

The json artifact can be copy-pasted or save-loaded from a file.

**Linked and Attached Files**

For a corpus linked to a Context server, the connection settings and file list will be exported. The subsequent import will attempt to re-connect and validate the file list.

For an attached corpus, the export will contain the corpus name and a file list. The user will have to re-attach the file manually.

**Context Server Inference Engines**

For a linked inference engine (LLM), export the settings to allow a reconnection.
