# UI Tweaks IV

## Project Tree

- Clicking a folder will expand/collapse it
- Add "New Folder" and "New Plan" items to the folder's menu items.

## LLM Page

- Put LLM Details in a popup window.
- Put LLM Prompt Packaging in a popup window.
- Prompt Packaging:
    - "List of other Context Documents" should be an actual list of other Context documents. Each should be individually checkable.
    - "List of waiting LLM threads" should be an actual list of waiting LLM threads. Each should be individually checkable.
    - There should be a character and token count displayed for the prompt.
- Run Details:
    - The dropdown list of plans should be ordered in the same way as they are in the project tree. Same order, grouping, and indentation.
    - There is something weird with the Review, Build, and Session buttons. Their enable/disable logic seems off or unintuitive.
- Log Details:
    - Put the run details in a popup window.
    - The prompt and output of the run log should be formatted, not markdown source.
    - There should be a character and token count displayed for the prompt and the output.

## Workspace Page

- Display the list of files which are included in the workspace and should update for every change to the filters.

And this is where we add git-ness.
- If there are no folders or files in the root path, prior to any filtering, then a `Checkout` button will be available to perform a git checkout into the root folder.
- If the root contains a `.git` folder, then it will have buttons to do `Commit` and `Push`. There will also be a browsable list of recent commits (pending and pushed). A pending commit will show the affected files and an accumulation of all un-commited build logs.

## Monaco Editor

- Allow the ciew to scroll past the end of the content. I like to see the empty space at the bottom of a document.
