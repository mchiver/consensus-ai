# Accounts and Roles

## Server Accounts

There will be a User Registry which ties an email address to a specific User in Consensus.

### Account Types

- **Administrator**:
  - Full access to the Server.
  - Manage User accounts.
  - Manage LLM Tasks.
  - Create and delete Projects.
  - Assign Project Roles.
- **User**:
  - Access to specific Projects when assigned a Project Role..
  - Can use any LLM Task in that Project..

## Project Roles

A Role determines what a user can see and do within a project.
Roles are defined per server and are applied per project.

- **Owner**: Full access to the Project. Can define LLM Tasks for Project.
- **Member**:  Read and Write access to the Project. Can use any LLM Task.
- **Service**: Read and Write access to the Project. Cannot use any LLM Task. Gets Task specific Read/Write Tool usage.
- **Watcher**: Read-only access to the project and threads. Access to the read-only `Explain` LLM Task.
