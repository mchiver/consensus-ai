# Accounts and Roles

## Server Accounts

There will be a User Registry which ties an email address to a specific User in Consensus.

### Account Types

- **Administrator**: Full access to the Server. Define available LLM Tasks.
- **User**: : Can use Projects. Can use any LLM Task.


## Project Roles

- When a User has access to a Project, they are given a Role.
- A Role determines what a user can see and do within a project.
- Roles are defined per server and applied per project.

### Project Roles

Project specific access is provided by 
A Project also defines the available tasks.

- **Owner**: Full access to the Project. Can define LLM Tasks for Project.
- **Member**:  Read and Write access to the Project. Can use any LLM Task.
- **Service**: Read and Write access to the Project. Cannot use any LLM Task. Gets Task specific Read/Write Tool usage.
- **Watcher**: Readonly access to the project and threads. Access to the read-only `Explain` LLM Task.
