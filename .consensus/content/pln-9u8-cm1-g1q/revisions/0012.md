# UI Tweaks III

- **Item actions menu.** Each row of the project tree gets one ⋯ button at its right end, opening a drop-down menu of that item's actions, in place of today's row buttons. The ⋯ shows on the hovered row and on the current item's row; right-clicking a row opens the same menu.
  - project: New plan, New document, New folder, Link a corpus, Upload a zip, Paste, Rename, Delete (the open project's + plan, + doc, + folder, + link and + zip buttons move into it)
  - folder: Paste, Copy, Rename, Delete
  - plan: New Subplan, Rename, Copy, Delete
  - document: Rename, Copy, Delete
  - corpus: Rename, Copy, Delete
  - the Context row has no menu.
  Delete asks to confirm on the row itself (delete? Yes / No). The badges stay on the row.

- **Delete only in the menu.** The Delete button leaves the content panel: from a plan's and a document's heading, and from a corpus's view (whose Rename moves to its menu too; Replace zip and Reload stay in the view). Delete is in the item's actions menu only.

- In the Project tree view, the currently selected/open Project should carry a solid green dot. All other Projects should carry a hollow circle.

- Need some window management: maybe a popup menu with "Close All", "Close All Except This One", etc. You can add "Detach" and "Reattach" to that menu. Keep the close button on the tab, add a drop-down menu in place of the detach button. Similar to the project item treatment.
