# UI Tweaks VI

- Change the verbiage on the "Reply and Resolve" button to read "Contest" and make it the same color as the "Contested" thread state.

- Using `Ctrl+S` to save an edited document should not exit edit mode.

- Add a top-level menu item called "Help". it will have have the following sub menus:
    - About:
        - Consensus version
        - link to source
        - link to online guide
        - summary of each project showing total number of threads, number contested, number waiting on me, and number waiting on LLM.
    - Settings: Show the existing settings popup
    - Hotkeys: The list of available hotkeys

- Hotkeys:
    - Ctrl+E: switches between Read and Edit. Switching from read to edit also saves the document.
    - Ctrl+S: saves in the editor and shows a toast on success.
    - Ctrl+C and Ctrl+V: copy and paste an item's export on the open item.
    - Escape: closes menus and popups.
    - Ctrl+Shift+E: show/hide the project tree explorer
    - Ctrl+Shift+T: show/hide the threads
    - Ctrl+Shift+C: add a document level comment to the current document
    - Ctrl+PgUp: Focus previous tab, wrap/loop to last
    - Ctrl+PgDown: Focus next tab, wrap/loop to first
    - Ctrl+Home: Focus first tab
    - Ctrl+End: Focus last tab

- When a plan tab is detached and displayed in its own window, there needs to be a way to toggle the visibility of the threads panel. Currently, the detached window inherits the current threads panel visibility with no way to toggle it.

- Clicking on anchor text in the plan view will select the associated thread, however, we have no way to deselect the current thread. make it so that clicking outside of any anchored text will deselect the current thread.

- Project Tree
    - Projects should be more indented underneath the server nodes.
    - Servers and Projects need a nice icon.
