# Consensus UI Tweaks

- (completed) Threads should support markdown.
- Use Golden Layout to do resizing and support multiple tabs in the central document view section.
- Proposals/Plans should be opened into new tabs that can be dragged to reorder and detach into a window.
- Plan Header: keep Read/Edit/Revisions on the first line with the title; move the buttons after them (Comment on the whole document, Send to LLM, Delete) to a new line, pulled to the right.
- Plans and documents should have copy and rename icons.
- Ability to reorder project folders with drag-drop.
- show/hide button for the threads.
- show/hide button for the markdown preview while editing.
- the indentation of child nodes within the project tree needs to be increased and the tree structure needs to be more pronounced. It currently just looks like a list.
