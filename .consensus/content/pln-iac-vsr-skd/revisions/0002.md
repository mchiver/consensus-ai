# Multiuser

Currently, we have a two-party system: User and LLM. The flow is to pass control from one party to the other until a consensus is achieved.

As we open up Consesnus to a Team work environment, we need to account for a Multi-Party system.
What constitutes consensus (or resolved) within a thread? Is it a majority or unanimity? Is it per Project?
How does an LLM Task get invoked within the control passing flow of the other members?
Default behavior is that any member can invoke LLM Tasks at any time.
