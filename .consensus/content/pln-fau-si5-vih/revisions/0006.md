# UI Tweaks V

- The current thread can be selected by clicking on anchored text. The threads pane lists the threads the filter matches plus the selected thread, at its place in the text order: the selected thread stays listed whatever the filter, until another thread is picked or the selection is cleared.

- When selecting text, a popup is shown allowing "Comment" and "New Subplan" commands. A "Copy" command is also available: it puts the selected text on the clipboard as it reads (plain text) and clears the selection. Copy is offered on documents too, where Comment and New Subplan are not.

- The plan state called "Proposal" is renamed to "Draft". The default plan states are "Draft", "Plan", "Working" and "Finished". A server whose settings list "Proposal" and not "Draft" renames it once at startup, in the settings and in every plan in that state. The "New Draft" commands in the menus below are labelled "New " + the first configured state, so with the defaults they read "New Draft". The docs (the guide's settings and projects pages, the readme) follow.

- The connected server should be displayed plainly in the little connection panel next to the Settings button.

- The state of the Prroject Tree for a specific server should be remembered between sessions. This includes current project, open/closed folders, sort order, open tabs, etc. The view state.

- The show/hide threads button should appear like the show/hide projects button: a small icon in the right side of the tab area.
