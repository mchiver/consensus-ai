# Step 6: Licensing

The three tiers, where they are read from and where they are enforced, and the Desktop's sign-in.

## What is built

- **The tiers in Clerk.** The license metadata becomes `License: { Plan: "personal" | "professional", Until }` on the user, with `Seats` on an organization as the Clerk subplan says; the session token template carries it as today. The server reads the new names only: no license has been sold under the old ones.
- **What each tier enforces.** Free: the Desktop on local folders and the sidecar, the LLM task buttons disabled with the reason. Personal: the task buttons, Connect to Host, Start the Server Host with Scope Local, the Host's management pages. Professional: the Host's Scope Public and the Administrator of a Public server. The Host refuses Public at bind time with a line naming the tier, so the check is one place; the API keeps the three sign-in checks the Clerk subplan names, reading the new plan names.
- **The Desktop signs in.** Sign in under the account menu loads ClerkJS in the page as a Public server does and shows the sign-in box; the session's license claim and the time are written to desktop.json's `License: { Plan, Until, Checked }`. The Desktop is Personal or Professional while Checked is within 14 days and Until has not passed, and asks Clerk again when the window opens online. About shows the tier and the days left offline. Sign out clears it. Free needs no account.
- **Connecting to a Host** reuses the session: the page sends the session token to the Host as a browser does, and the Host's own checks apply.
- **The pricing page** on the website names Free, Personal and Professional with what each grants, from the plan's Licensing section, and the Clerk subplan's license section is brought in line.

## Checks

`test/Clerk.test.js`: the new plan names read, the old refused. `test/Api.test.js`: Public refused at bind without Professional, the sign-in checks with each tier. `test/Desktop.test.js` with a generated key pair as the Clerk tests do: the cached license within and past 14 days, Until passed, sign out. `test/ClerkSmoke.test.js` gains the Desktop sign-in when the keys are set.
